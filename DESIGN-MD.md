Arquivos DESIGN.md de produtos reais
===

Catálogo do [awesome-design-md](https://github.com/VoltAgent/awesome-design-md), da
VoltAgent: uma coleção de arquivos `DESIGN.md` que descrevem a linguagem visual de produtos
conhecidos (Claude, Linear, Stripe, Vercel...). A ideia de uso é direta: você copia um
`DESIGN.md` para o seu projeto e diz ao agente *"faça uma página com esta cara"* — e o
resultado sai coerente com aquele estilo.

> **Como ler esta lista.** Ela é diferente do [README](README.md), onde cada item passou por
> análise individual. Aqui são 73 arquivos importados em bloco: os títulos das categorias
> estão em português, mas **as descrições de estilo permanecem no original em inglês**, como
> vêm da fonte. Cada link leva ao `DESIGN.md` correspondente em getdesign.md. Trate como um
> índice de referências visuais, não como avaliação individual.

**O que é um DESIGN.md.** É um documento em Markdown que codifica a identidade visual de um
produto — paleta, tipografia, espaçamento, tom — num formato que um agente de código
consegue seguir. Aparece como conceito central em dois achados da lista principal: o
[impeccable](achados/2026-08-21-impeccable-design-language-e-skill-para-agentes-de-codigo.md)
gera um por entrevista, e o
[OpenDesign](achados/2026-08-28-opendesign-gerador-de-artefatos-de-design-dirigido-por-agent.md)
traz 151 embutidos. Esta coleção é a terceira fonte — e a mais fácil de garimpar por marca.

## Como usar isto

Ideias a partir destes arquivos, inclusive cruzando com a esteira de interface da lista
principal, estão em [`IDEIAS-DESIGN-MD.md`](IDEIAS-DESIGN-MD.md).

Para procurar aqui, use `grep` sobre a fonte tabular:

```bash
grep -i "dark" dados/design-md.tsv | cut -f2,4
awk -F'\t' '$1 ~ /Fintech/' dados/design-md.tsv | cut -f2,3
```

Para atualizar quando a fonte mudar:

```bash
curl -sSL -o /tmp/adm.md \
  https://raw.githubusercontent.com/VoltAgent/awesome-design-md/main/README.md
python3 scripts/importar_design_md.py /tmp/adm.md
python3 scripts/indexar_design_md.py
```

as marcas citadas pertencem aos respectivos donos.</sub>
